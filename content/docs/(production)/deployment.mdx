Protoform deploys as one static artifact:

- Blume documentation under `/docs`;
- built shadcn registry JSON under `/r`;
- interactive examples backed by in-browser Connect transports.

The static deployment has no application server, accounts, database, or cold starts. The bookstore
keeps its temporary state in the browser and resets when the page reloads.

## Deploy with Cloudflare Pages

Import `malinskibeniamin/protoform` as a Pages project and use these settings:

| Setting | Value |
| --- | --- |
| Production branch | `main` |
| Build command | `bun run build` |
| Build output directory | `dist` |
| Root directory | repository root |

Pin the toolchain under **Settings → Environment variables**:

| Variable | Value |
| --- | --- |
| `BUN_VERSION` | `1.4.0` |

Cloudflare rebuilds the site after each push to `main`. If the Pages project is named `protoform`,
the public endpoints are:

```text
https://protoform.pages.dev/docs
https://protoform.pages.dev/r/{name}.json
https://protoform.pages.dev/r/protoform.json
```

Configure shadcn to install current source from the Pages deployment:

```json
{
  "registries": {
    "@protoform": "https://protoform.pages.dev/r/{name}.json"
  }
}
```

```bash
bunx shadcn@latest add @protoform/protoform
```

Use the actual `*.pages.dev` hostname shown by Cloudflare if `protoform.pages.dev` is unavailable.
A custom domain can later expose the same paths, such as `https://protoform.dev/docs` and
`https://protoform.dev/r/{name}.json`.

## Verify locally

```bash
bun install --frozen-lockfile
bun run build
bun run start
```

Open `http://localhost:8080/docs` and
`http://localhost:8080/r/protoform.json`.

## Release a source snapshot

The hosted `/r` endpoint contains the current source from `main`. Keep stable installs pinned to an
immutable Git tag:

```text
https://raw.githubusercontent.com/malinskibeniamin/protoform/v1.0.0/public/r/{name}.json
```

A `v*` Git tag must match `package.json`; the release workflow runs the quality and security gates
before creating an archive, checksum, provenance attestation, and GitHub release.
