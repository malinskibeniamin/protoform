---
title: "MCP for agents"
description: "Connect an agent to Protoform's read-only documentation server."
---

Protoform publishes the generated documentation as a read-only Model Context Protocol server.
Use the streamable HTTP endpoint at `/mcp` on the same origin as this site.

Discovery metadata is available at:

- `/.well-known/mcp.json`
- `/.well-known/mcp/server-card.json`

For local development, start the docs and connect to `http://127.0.0.1:55011/mcp`.
For deployed docs, replace the origin and keep the `/mcp` path.

```json
{
  "mcpServers": {
    "protoform-docs": {
      "type": "http",
      "url": "http://127.0.0.1:55011/mcp"
    }
  }
}
```

The endpoint exposes four read-only tools:

- `search_docs` finds focused guides, AIP examples, and API operations.
- `get_page` returns one page as agent-optimized Markdown. Live `<Component>` previews become
  fenced source code.
- `list_pages` enumerates every route and content type.
- `get_navigation` returns the generated documentation hierarchy.

Start with `search_docs`, pass a returned route to `get_page`, then install or adapt the registry
example from that page. The server does not expose mutation, filesystem, shell, or registry-write
tools.
