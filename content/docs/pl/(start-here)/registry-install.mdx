title: Instalacja z rejestru
description: "Instalowanie elementów rejestru Protoform przez shadcn, weryfikacja zależności i uruchamianie formularzy protobuf w istniejącej aplikacji React."
---
Protoform jest dystrybuowany jako niestandardowy rejestr w stylu shadcn. Możesz zainstalować pełny zestaw lub wybrać mniejszy punkt wejścia.

## 1. Dodaj przestrzeń nazw rejestru

```json title="components.json"
{
  "registries": {
    "@protoform": "https://raw.githubusercontent.com/malinskibeniamin/protoform/v1.0.0/public/r/{name}.json"
  }
}
```

Zachowaj przypięty tag Git oraz ścieżkę `/r/{name}.json`, aby shadcn mógł rozpoznać każdy
element `@protoform`.

## 2. Wybierz cel instalacji

Rejestr kopiuje cały kod źródłowy Protoform do aplikacji i instaluje wyłącznie publiczne zależności
zewnętrzne. Rejestr npm Protoform ani token pakietu nie są wymagane.

```bash
# Hook only: React Hook Form + ProtoValidate + server error mapping
bunx shadcn@latest add @protoform/protoform-core

# AutoForm renderer: uses your components.json ui alias
bunx shadcn@latest add @protoform/protoform-react

# Optional default shadcn UI implementations for greenfield apps
bunx shadcn@latest add @protoform/protoform-shadcn

# Experimental React Hook Form v8 beta hook
bunx shadcn@latest add @protoform/use-proto-form-v8

# Experimental React Hook Form v8 beta AutoForm
bunx shadcn@latest add @protoform/auto-form-react-hook-form-v8

# Native TanStack Form hook
bunx shadcn@latest add @protoform/use-proto-form-tanstack

# TanStack Form AutoForm
bunx shadcn@latest add @protoform/auto-form-tanstack

# Experimental TanStack Form v2 alpha hook
bunx shadcn@latest add @protoform/use-proto-form-tanstack-v2

# Experimental TanStack Form v2 alpha AutoForm
bunx shadcn@latest add @protoform/auto-form-tanstack-v2

# Default React Hook Form stack
bunx shadcn@latest add @protoform/protoform

# Demos and generated example schemas
bunx shadcn@latest add @protoform/protoform-examples

# Complete five-RPC bookstore
bunx shadcn@latest add @protoform/bookstore
```

## Warstwy rejestru

| Element | Kiedy używać | Zawiera |
| --- | --- | --- |
| `protoform-core` | Masz już interfejs formularza shadcn i chcesz korzystać z walidacji protobuf | `useProtoForm`, resolver ProtoValidate, narzędzia pomocnicze oneof, mapowanie błędów Connect/gRPC |
| `use-proto-form-v8` | Oceniasz wersję beta React Hook Form v8 | Oddzielny natywny hook v8 przypięty do `8.0.0-beta.3` |
| `use-proto-form-tanstack` | Korzystasz już z TanStack Form | Natywne API TanStack oraz komunikaty protobuf, maski aktualizacji, pola oneof i błędy serwera |
| `protoform-react` | Chcesz pól generowanych ze schematu z domyślnym silnikiem | Współdzielony renderer oraz adapter React Hook Form |
| `protoform-shadcn` | Chcesz domyślne UI dla nowej aplikacji | `protoform-react` oraz opcjonalne implementacje shadcn instalowane w `components/ui` |
| `auto-form-react-hook-form-v8` | Oceniasz pola generowane w wersji beta React Hook Form v8 | Oddzielny natywny adapter AutoForm v8 oraz współdzielony renderer |
| `auto-form-tanstack` | Chcesz pól generowanych ze schematu z TanStack Form | Współdzielony renderer oraz adapter TanStack Form |
| `use-proto-form-tanstack-v2` | Oceniasz wersję alfa TanStack Form v2 | Oddzielny natywny hook v2 przypięty do `2.0.0-alpha.2` |
| `auto-form-tanstack-v2` | Oceniasz pola generowane w wersji alfa TanStack Form v2 | Oddzielny natywny adapter AutoForm v2 oraz współdzielony renderer |
| `auto-form-core` | Utrzymujesz adapter silnika | Renderer niezależny od silnika, instalowany przez oba elementy AutoForm |
| `protoform` | Chcesz korzystać z domyślnego zestawu funkcji produktu | Rdzeń, renderer React i domyślne implementacje UI shadcn |
| `protoform-examples` | Potrzebujesz demonstracyjnych implementacji referencyjnych | Wygenerowane przykładowe schematy i komponenty demonstracyjne |
| `bookstore` | Potrzebujesz jednej kompletnej historii RPC | Pięć metod, wygenerowane powiązania, formularze i tymczasowa usługa |

## Dlaczego ten podział?

`protoform-core` zawiera konwersję protobuf, walidację i `useProtoForm`, bez importów UI.
`protoform-react` dodaje renderowanie AutoForm i logikę pól, a wymagane możliwości UI rozwiązuje
przez alias `ui` w `components.json`. Dojrzałe aplikacje mogą skierować ten alias na kanoniczną
fasadę `components/ui/*`, złożoną z bezpośrednich reeksportów lub cienkich adapterów zgodności.

`protoform-shadcn` to opcjonalna domyślna implementacja dla nowych aplikacji. Instaluje moduły UI
w `components/ui`, nie włączając ich do renderera React. Nadpisania `AutoFormUIComponents` dla
konkretnego formularza pozostają skupione na formularzu, opakowaniach pól, przycisku wysyłania,
opakowaniach kolekcji i błędach, zamiast wstrzykiwać każdy prymityw w czasie działania.

## Przypnij migawkę źródła

Hostowany rejestr zawiera aktualny kod źródłowy. Aby instalacja była powtarzalna, przypnij przestrzeń nazw do tagu
Git:

```json title="components.json"
{
  "registries": {
    "@protoform": "https://raw.githubusercontent.com/malinskibeniamin/protoform/v1.0.0/public/r/{name}.json"
  }
}
```

```bash
bunx shadcn@latest add @protoform/protoform
```

Aktualizacja jest wykonywana jawnie: ponownie uruchom `shadcn add`, przejrzyj różnice w kodzie źródłowym, a następnie zachowaj lub dostosuj zmiany.
