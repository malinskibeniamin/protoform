## Co dodaje ten przykład

- Wymagane pole `oneof` z dwiema skalarnymi gałęziami.
- Jedna aktywna gałąź o określonym typie w przesłanej wiadomości.
- Automatyczne czyszczenie po zmianie wybranej gałęzi.

## Kontrakt

```proto
message OneofForm {
  oneof contact {
    option (buf.validate.oneof).required = true;
    option (protoform.v1.oneof_ui).description = "Choose one contact method.";

    string email = 1;
    string phone = 2;
  }
}
```

Wprowadź adres e-mail, przełącz się na Telefon, a następnie prześlij formularz. Wiadomość o określonym typie zawiera tylko gałąź telefonu; ukryty adres e-mail zostaje wyczyszczony, zamiast stać się osieroconymi danymi.
