## 新增内容

- 包含两个标量分支的必填 `oneof`。
- 提交的消息中仅包含一个类型明确的活动分支。
- 所选分支更改时自动清理。

## 契约

```proto
message OneofForm {
  oneof contact {
    option (buf.validate.oneof).required = true;
    option (protoform.v1.oneof_ui).description = "Choose one contact method.";

    string email = 1;
    string phone = 2;
  }
}
```

输入电子邮件地址，切换到“电话”，然后提交。类型化消息仅包含电话分支；隐藏的电子邮件地址会被清除，而不会成为幽灵数据。
