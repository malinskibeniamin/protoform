## 新增内容

- 一条具有稳定 ID 的字段级 CEL 规则。
- 一个 RE2 兼容的正则表达式。
- 一条面向用户的验证消息。

## 契约

```proto
message CelRe2Form {
  string project_id = 1 [(buf.validate.field).cel = {
    id: "project_id.re2"
    message: "Use lowercase letters, digits, and hyphens."
    expression: "this.matches('^[a-z][a-z0-9-]*$')"
  }];
}
```

先尝试 `Not valid`，再尝试 `payments-prod`。这里使用 CEL 字符串匹配，而不是 JavaScript `RegExp`，因此模式应遵循各运行时均支持的 [RE2 语法](https://github.com/google/re2/wiki/Syntax)。

仅当规则确实需要比较多个字段时，才使用消息级 CEL。单字段规则应附加到对应字段，以确保错误路径准确。
