## 分享并继续

所选预设和预览模式会保留在页面 URL 中。使用工作区页脚复制其代码
或 Bun 命令，或在 shadcn/create 中继续使用相同的预设。

## 范围

Protoform 目前在其 registry 中维护 Base UI + Nova 组件源码。其他组件基础
和样式可能会改变组件结构和 API，因此无法通过替换 CSS
变量来模拟。支持另一种样式属于源码级兼容性功能，而不是此实验工具中的另一个颜色
选项。
