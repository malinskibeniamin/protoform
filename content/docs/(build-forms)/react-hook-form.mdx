The shadcn React Hook Form guide starts with Zod. Protoform keeps the same UI shape, but replaces
the schema resolver with a protobuf descriptor. React Hook Form remains the default engine and the
reference behavior for Protoform.

```bash
bunx shadcn@latest add @protoform/use-proto-form
```

```tsx
import { Controller } from "react-hook-form";
import { Button } from "@/components/ui/button";
import { Field, FieldError, FieldLabel } from "@/components/ui/field";
import { Input } from "@/components/ui/input";
import { useProtoForm } from "@/hooks/use-proto-form";
import { SignupRequestSchema } from "@/gen/example/v1/signup_pb";

export function SignupForm() {
  const form = useProtoForm(SignupRequestSchema, {
    defaultValues: { email: "", displayName: "" },
  });

  return (
    <form onSubmit={form.handleSubmit((values) => console.log(form.createMessage(values)))}>
      <Controller
        control={form.control}
        name="email"
        render={({ field, fieldState }) => (
          <Field data-invalid={fieldState.invalid}>
            <FieldLabel htmlFor={field.name}>Email</FieldLabel>
            <Input {...field} id={field.name} aria-invalid={fieldState.invalid} />
            {fieldState.invalid ? <FieldError errors={[fieldState.error]} /> : null}
          </Field>
        )}
      />
      <Button type="submit">Create account</Button>
    </form>
  );
}
```

## What you get

- `resolver: createProtoResolver(schema)` under the hood.
- `createMessage(values)` to convert form values into a protobuf message.
- `createUpdateMask()` to include only dirty, writable protobuf paths in an update request.
- `setOneofValue(path, case, value)` for oneof-safe updates.
- `setServerErrors(error)` to map Connect/gRPC field violations back into RHF.

The return value is the complete `UseFormReturn`, so existing `Controller`, `useFieldArray`,
`watch`, `reset`, resolver options, and uncommon React Hook Form patterns remain available.

## Generate the fields

The default registry item uses React Hook Form:

```bash
bunx shadcn@latest add @protoform/auto-form
```

```tsx
import { AutoForm } from "@/components/auto-form";
import { SignupRequestSchema } from "@/gen/example/v1/signup_pb";

export function SignupForm() {
  return (
    <AutoForm
      schema={SignupRequestSchema}
      formOptions={{ shouldFocusError: true }}
      validationMode="blur"
      revalidationMode="change"
      onFormInit={(form) => {
        // Full React Hook Form API.
        form.watch("email");
      }}
      onSubmit={async (message, form, { updateMask, signal }) => {
        await client.signup(message, { signal });
        console.log(form.formState.isDirty, updateMask?.paths);
      }}
      withSubmit
    />
  );
}
```

`formOptions` is passed to `useForm`. `onFormInit`, `onFieldChange`, and `onSubmit` receive the
native React Hook Form instance. Protoform adds generated rendering without replacing the API you
already know.

Already standardized on another form store? See the native hook and generated AutoForm path in
[TanStack Form](/docs/tanstack-form), or the
[Formik](/docs/formik) and [Final Form](/docs/final-form) adapters.
