## Share and continue

The selected preset and preview mode stay in the page URL. Use the workspace footer to copy its code
or Bun command, or continue with the same preset in shadcn/create.

## Scope

Protoform currently owns Base UI + Nova component source under its registry. Other component bases
and styles can change component structure and APIs, so they are not simulated by swapping CSS
variables. Supporting another style is a source-level compatibility feature, not another color
option in this lab.
