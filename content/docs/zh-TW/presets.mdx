## 分享並繼續

所選的預設配置和預覽模式會保留在頁面 URL 中。使用工作區頁尾複製其程式碼
或 Bun 指令，或前往 shadcn/create 繼續使用相同的預設配置。

## 範圍

Protoform 目前在其 registry 中維護 Base UI + Nova 元件原始碼。其他元件基礎
和樣式可能會改變元件結構與 API，因此無法僅透過替換 CSS
變數來模擬。支援其他樣式是原始碼層級的相容性功能，並非此實驗室中的另一個色彩
選項。
