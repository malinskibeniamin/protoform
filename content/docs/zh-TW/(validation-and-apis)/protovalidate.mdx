---
title: Protovalidate
description: 將用戶端與伺服器端驗證保留在 protobuf 契約中。
---
Protoform 使用 Protovalidate ES，因此驗證規則來自 `buf.validate` 註解。
相同的欄位規則與 CEL 不變條件可在瀏覽器和伺服器執行環境中運作，無須在僅供前端使用的 schema 中重新建立契約。

[正式環境就緒度儀表板](/docs/production-readiness)會分別追蹤每個已安裝的標準規則系列，
因此不會將少數常見的字串和數字範例誤認為完整涵蓋。

```proto
message CreateTopicRequest {
  string name = 1 [(buf.validate.field).string = {
    pattern: "^[a-z][a-z0-9-]{2,62}$"
    min_len: 3
    max_len: 63
  }];

  int32 partitions = 2 [(buf.validate.field).int32 = {
    gte: 1
    lte: 1000
  }];
}
```

```tsx
const form = useProtoForm(CreateTopicRequestSchema, {
  mode: "onChange",
  defaultValues: { name: "", partitions: 3 },
});
```

不同於獨立的 Zod schema，當 protobuf 契約演進時，這仍能正確驗證。

## Standard Schema 互通性

protobuf 套件將 Protovalidate 公開為
[Standard Schema v1](https://standardschema.dev/) 實作。`createProtoFormSchema` 接收表單值，
透過產生的 protobuf descriptor 進行驗證，並在成功時傳回具型別的 protobuf 訊息。
其問題路徑採用表單結構，包括攤平的 oneof 和 map 項目。

```tsx
import { standardSchemaResolver } from "@hookform/resolvers/standard-schema";
import { createProtoFormSchema } from "@/lib/protobuf-provider";
import { useForm } from "react-hook-form";

const schema = createProtoFormSchema(CreateTopicRequestSchema);
const form = useForm({
  resolver: standardSchemaResolver(schema),
});
```

這是供其他 Standard Schema 使用端或表單框架使用的中立互通介面。TanStack
Form 可原生接受此 schema；Formik 和 Final Form 則使用不含相依套件的
[Formik](/docs/formik) 與 [Final Form](/docs/final-form) 轉接器。
使用 React Hook Form 的 Protoform React 應用程式通常應優先採用 `useProtoForm`。其自訂
resolver 提供 protobuf 專用錯誤對應、一般訊息人性化、原生驗證支援，以及根層級 CEL 錯誤處理。

請參閱 [Standard Schema](/docs/standard-schema)，了解完整功能矩陣、Zod 4 與 Zod Mini
相容性證據、轉接器用法，以及驗證與 AutoForm 呈現之間的界線。

## Protoform 與 Zod 比較

| 關注面向 | Zod 優先表單 | Protoform |
| --- | --- | --- |
| API 契約 | 在 TypeScript 中重新建模 | 以 Protobuf 為單一事實來源 |
| 執行階段驗證 | Zod resolver | Protovalidate resolver |
| 伺服器一致性 | 手動同步 | 使用相同的註解與 CEL 規則 |
| 型別 | `z.infer` | `MessageShape<typeof Schema>` 加上 oneof 攤平 |
| Wire 格式 | 個別轉換 | 輸出具型別的 protobuf 訊息 |
| 跨欄位規則 | `refine` | CEL 運算式 |
| 程式庫互通性 | Zod API | Standard Schema v1 |
