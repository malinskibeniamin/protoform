## 新增內容

- 包含兩個純量分支的必填 `oneof`。
- 提交的訊息中僅有一個具型別的作用中分支。
- 所選分支變更時自動清除資料。

## 合約

```proto
message OneofForm {
  oneof contact {
    option (buf.validate.oneof).required = true;
    option (protoform.v1.oneof_ui).description = "Choose one contact method.";

    string email = 1;
    string phone = 2;
  }
}
```

輸入電子郵件、切換至「電話」，然後提交。具型別的訊息只包含電話分支；隱藏的電子郵件會被清除，而不會成為幽靈資料。
