## 此範例新增的內容

- 一項具有穩定 ID 的欄位層級 CEL 規則。
- 一個 RE2 相容的規則運算式。
- 一則向使用者顯示的驗證訊息。

## 契約

```proto
message CelRe2Form {
  string project_id = 1 [(buf.validate.field).cel = {
    id: "project_id.re2"
    message: "Use lowercase letters, digits, and hyphens."
    expression: "this.matches('^[a-z][a-z0-9-]*$')"
  }];
}
```

先嘗試 `Not valid`，再輸入 `payments-prod`。此處使用 CEL 字串比對，而非 JavaScript
`RegExp`，因此請確保模式符合各執行環境支援的 [RE2 語法](https://github.com/google/re2/wiki/Syntax)。

只有在規則確實需要比較多個欄位時，才使用訊息層級 CEL。單一欄位規則應附加至該欄位，
讓錯誤路徑保持精確。
