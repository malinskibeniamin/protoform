## What this adds

- A required `oneof` with two scalar branches.
- One typed active branch in the submitted message.
- Automatic cleanup when the selected branch changes.

## Contract

```proto
message OneofForm {
  oneof contact {
    option (buf.validate.oneof).required = true;
    option (protoform.v1.oneof_ui).description = "Choose one contact method.";

    string email = 1;
    string phone = 2;
  }
}
```

Enter an email, switch to Phone, then submit. The typed message contains only the phone branch; the
hidden email is cleared rather than becoming ghost data.
