# Dependency ledger

Every direct package in `package.json` has one row here, saying why it is installed and how its
cost is kept down. `scripts/dependency-ledger.test.ts` fails when a package is added, removed or
moved between `dependencies` and `devDependencies` without updating this file.

`dependencies` holds code that runs for someone: registry consumers, the docs site or the example
apps. `devDependencies` holds build, codegen, lint, type and test tooling. The project is
private, so the split records intent and does not change what npm publishes.

Bundle numbers are gzip bytes from `scripts/bundle-budget.integration.test.ts`. They measure the
fully resolved default-UI consumer probe, not network traffic, CSS, fonts or WASM.

## Removed

| Package                 | Why it was removed                                                                                          | Replacement                                                                                                                                                                                                                 |
| ----------------------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `motion`                | Added JavaScript to the initial UI load for animations CSS can express.                                     | CSS transitions on Base UI state attributes, `tw-animate-css` utilities and `motion-reduce` variants. Components no longer accept Motion `transition` props; hosts that want Motion pass a Motion element through `render`. |
| `@uiw/react-codemirror` | A React wrapper that also pulled in `@babel/runtime`, the `codemirror` meta-package and the One Dark theme. | Direct `@codemirror/*` extensions with the same editing behavior.                                                                                                                                                           |
| `date-fns` (direct)     | AutoForm used three functions from it.                                                                      | Native `Date` helpers. It remains a transitive dependency of `react-day-picker`, loaded only with `Calendar`.                                                                                                               |
| `oxlint-tsgolint`       | Unused since Oxlint's type-aware runner moved to `tsrs-lint`.                                               | `tsrs-lint`.                                                                                                                                                                                                                |
| `quickjs-emscripten`    | Umbrella package with every WASM variant.                                                                   | `quickjs-emscripten-core` and `@jitl/quickjs-wasmfile-release-sync`.                                                                                                                                                        |
