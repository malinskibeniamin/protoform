## Root repairs and proof

Recorded behavioral RED receipts cover full tooltip payload, zero series label, carousel caret keys, portal scope, action form-submit safety, Item separators, source stylesheet injection, mobile Message composition, narrow catalog tabs and accessibility contrast/landmarks. Consumer fixture separately caught Pagination asChild rewriting to an incompatible installed Button render prop. Existing native policy tests caught missing dev type-package role and Field wrappers; no exemptions added.

Chart config is caller-owned presentation, not untrusted executable CSS text: scoped custom properties are applied through CSSOM and cleaned up, never interpolated into a style element. Heavy Recharts presentation primitives are lazy with Suspense. Compiler-owned context state is separated from provider composition; no manual memoization or new lint exceptions.

## Strongest counterargument

A full-catalog source-copy bundle adds meaningful installation and maintenance cost, increases review surface, and does not make customized APIs drop-in-compatible. Mitigation: explicit bounded catalog claim, immutable source/digests/MIT notice, direct module imports, lazy heavy examples/runtime, independent install-path coverage, consumer compilation and browser journeys. Do not claim speed, exact styling parity, complete upstream API parity, human endorsement or exhaustive arbitrary-content coverage.
